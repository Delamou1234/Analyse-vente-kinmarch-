📊 Tableau de Bord Interactif : Analyse des Ventes Kinmarche USA
Ce projet consiste en la création d'un tableau de bord analytique complet permettant de suivre la performance commerciale de Kinmarche sur le marché américain. L'objectif était de centraliser les indicateurs clés (KPI) pour faciliter la prise de décision stratégique.
🔑 Fonctionnalités Clés :
Analyse Temporelle : Un graphique linéaire détaillé compare les tendances de ventes mensuelles sur les années 2020 et 2021, mettant en évidence une croissance significative à partir de janvier 2021.
Segmentation Géographique : Une carte interactive des États-Unis visualise la répartition des ventes par région, permettant d'identifier instantanément les zones les plus performantes (ex: Sud et Nord-est).
Performance des Détaillants : Un graphique à barres horizontales classe les revenus générés par les principaux partenaires comme West Gear, Foot Locker et Sports Direct.
Répartition par Canal : Un graphique en secteurs (donut chart) analyse la distribution des ventes entre les canaux En ligne, En magasin et les Sorties.
Filtrage Dynamique : Une barre latérale intuitive permet de segmenter l'ensemble des données par année, par catégorie de produit (Chaussures, Vêtements) et par région.
🛠 Outils & Compétences :
Outil utilisé : [Excel]
Compétences démontrées : Visualisation de données (DataViz), Nettoyage de données, Analyse de tendances de marché et Conception d'interfaces utilisateur (UI).
